## 🚀 About The Project
This project features a high-quality, custom visual animation showcasing a portal-busting effect. The graphics transition smoothly through vibrant purple lightning storms and dynamic energy flows, culminating in a striking, polished gold geometric emblem.

## 🛠️ Technical Details & Optimization
To deliver an excellent user experience while maintaining a tiny footprint in the repository, the asset has been aggressively optimized using automated pipeline scripts:
* **Resolution:** Clean `360 × 640` viewport, perfect for mobile and desktop previewing.
* **Framerate:** Capped at a stable `12 FPS` to keep frame indexing highly efficient.
* **Color Palette:** Custom `128-color index map` that preserves the deep glowing gradients of the purple nebulae and the sharp specular highlights on the gold logo.
* **Compression:** Encoded with advanced delta-subrectangle compression to save data by only tracking pixel deviations against the dark space background.
* **Playback:** Configured for seamless, infinite looping.
