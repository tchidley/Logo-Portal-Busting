# Logo Portal Busting

Python-based video processing and visual effects project using OpenCV and NumPy.

![Logo Portal Animation](optimized_animation.gif)


## Project Files

| File | Description |
|---|---|
| `logo_portal_busting.py` | Editable Python source code |
| `logo_portal_busting.mp4` | Original source video |

## Requirements

Python 3 and the following libraries:

```bash
pip install opencv-python numpy
```

## How to Run

1. Download the Python script and original source video.
2. Place both files in the same folder.
3. Open the folder in Visual Studio Code.
4. Run the Python script:

```bash
python logo_portal_busting.py
```

5. The script generates `editable_energy_video.mp4` in the same folder.

## Editable Effects

- Brightness and contrast
- Saturation and gamma
- Glow enhancement
- Purple colour treatment
- Zoom and image positioning
- Fade-in and fade-out
